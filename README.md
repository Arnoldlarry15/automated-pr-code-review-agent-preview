## 🛠️ Architecture & Specifications
- **Runtime:** Python 3.11+
- **Execution Environment:** GitHub Actions (`ubuntu-latest`)
- **Default LLM Provider:** Groq (`llama-3.3-70b-versatile`)
- **Compatibility:** Any OpenAI-compatible chat completions endpoint (OpenAI, Anthropic via proxy, vLLM, Ollama)
- **Token Protection:** Automated diff truncation at 25,000 characters to safeguard context budgets.
- **Security Scope:** OWASP Top 10, CWE flaw patterns, unhandled exceptions, and credential leaks.
